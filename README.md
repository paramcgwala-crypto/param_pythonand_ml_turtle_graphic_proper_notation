## How to run

```bash
git clone https://github.com/paramcgwala-crypto/param_pythonand_ml_turtle_graphic_proper_notation.git
cd param_pythonand_ml_turtle_graphic_proper_notation
python -m venv .venv
# Windows: .venv\Scripts\activate    |    Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

Each notebook uses the dataset stored in its own folder. Two very large files (`MetroPT3(AirCompressor).csv` and `creditcard.csv`) are not included because of GitHub size limits.
